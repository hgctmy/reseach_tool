# 日本語版 Briefs 的な運用手順

alphaXivの「Briefs」（論文の音声要約フィード）に日本語版は無い。
自作パイプラインも検討したが、結局は既存ツール（alphaXiv + NotebookLM）を
そのまま組み合わせる方が手軽で保守も不要という結論になった。以下がその手順。

## 手順

1. **alphaXivで論文をチェックする**
   いつも通り https://www.alphaxiv.org/ でおすすめフィード・トレンドを眺める。
   テキストで読みたいだけなら「Blog」タブから日本語の解説記事も読める
   （URLの`arxiv`を`alphaxiv`に変えるだけでも起動できる）。

2. **音声で聞きたい論文だけNotebookLMに投げる**
   気になった論文のURL（arXivのURLやPDF）をNotebookLMの新しいノートブックの
   ソースとして追加する。

3. **NotebookLMの出力言語を日本語にする**（初回のみ）
   右上の設定 → Output Language を「日本語」に変更する。以降、音声・チャット
   応答がすべて日本語になる。

4. **Audio Overviewを生成する**
   ノートブック内で音声解説（Audio Overview）を生成する。数分待つと
   ポッドキャスト風の日本語音声ができる。

5. **通勤中などオフラインで聴きたい場合**
   生成された音声は「…」メニューからダウンロードできる。Google Drive等の
   同期フォルダに置いておけば、スマホの公式アプリで事前ダウンロードしておき、
   電波の無い場所でも標準の音楽/ファイルアプリで再生できる。

## メモ

- NotebookLMのAudio Overviewは2025年に50以上の言語に対応しており、日本語も
  含まれる（Settings > Output Language）。
- alphaXiv自体の非公開API連携やVOICEVOXによる自前音声合成パイプラインも
  一度試作したが、セットアップ・保守コストに見合わないと判断し、上記の
  シンプルな手動フローに切り替えた。
